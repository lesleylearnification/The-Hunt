# The Hunt: Nothing to See Here · V5

A five-minute browser-based cybersecurity learning-game prototype inspired by Huntress's brand and managed-defense value proposition.

## V5 improvements

- Fully anonymous hooded hacker artwork with the face completely obscured
- Progressive Huntress states: Quiet, Watching, Correlating, Hunting, Caught
- Categorized traces across Identity, Email, Endpoint, Cloud, Network, and Data
- In-the-moment defense-block feedback explaining what stopped the attacker and why
- Escalating visual tension as the player approaches Stage 5 or Huntress closes in
- Six visually differentiated randomized mission types
- End-of-run reconstruction connecting Action → Trace → Defense, with earliest prevention point
- Larger secondary/body text and stronger legibility
- Non-color-only status cues, visible focus states, keyboard controls, and reduced-motion support

## Run locally

Open `index.html` directly in a modern browser, or serve this folder with a simple local web server.

## GitHub Pages

Upload `index.html`, `style.css`, `game.js`, and the entire `assets` folder to the repository root. Enable GitHub Pages from the branch/root you use for the project.
